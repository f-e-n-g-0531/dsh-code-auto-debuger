# 张良 / Zhang Liang 0.2.0

- 新增独立的 Windows x64 性能分析栏。可从进程列表搜索并选择目标，一键录制并分析，也可导入工作区内的 ETL。录制系统 CPU 样本需要管理员权限。
- 可按 DXGI Present 间隔或手选时间范围查看分线程 CPU 热点与代表调用栈，区分自身采样和含子调用采样。Present 间隔不是游戏逻辑帧，采样估算不等于调用耗时。
- 支持本地 PDB（含本地绝对目录），并用 ETL 中的 GUID/age 校验匹配；没有匹配符号时显示模块和偏移。录制可按原会话恢复；关闭记录不会删除导入的原文件。
- 性能分析独立于 Visual Studio 调试，不注入、不暂停目标，不需要 WPR/WPA。不新增 AI 对话侧的性能工具；原有 VS 对话调试仍由原桥接组件提供。

详见[性能分析使用说明](<PROFILER.md>)。
