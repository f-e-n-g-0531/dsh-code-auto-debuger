# DSH Auto Debug 0.1.2

DSH 第三方插件，通过外部桥接控制 Visual Studio；不需要安装 VSIX。

## 功能

- 有时间和步骤预算的断点、启动、暂停、单步与调用栈采集。
- 明确预览和确认后执行；任务 ID 与请求 ID 支持找回原任务，不自动重复操作。
- 修复保存失败丢结果、切页和迟到响应导致状态丢失、目录切换后无法取消旧任务等问题。
- 补齐桥接流错误、断点部分成功恢复、精确进程清理及发布包完整性检查。

## 安装与使用

将安装包安装到 DSH 插件依赖目录，启用插件并重启 DSH，按[README](../README.md)连接目标 VS 实例、预览并执行有限调试计划。

## 兼容与限制

Windows x64、标准目录安装的 VS 2022；发布包自带 .NET 运行时。C++ 已验证精确断点命中、源行推进、调用栈、自有断点删除和清理。C#、全部扩展动作及当前真实 DSH GUI 安装未完整验收。取消任务不代表目标程序停止。
